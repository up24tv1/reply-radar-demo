# Reply Radar — demo

Never leave a customer on read. Paste in a booking request, refund question or complaint, and Reply Radar:

- triages it by category (booking, refund/billing, order, account, complaint), priority and language (EN/FR) with simple in-browser rules
- starts a reply-target countdown and flags anything past target in red
- writes a ready-to-send acknowledgement you can copy, then mark as answered

It's 100% static (HTML/CSS/JS). There are no APIs or keys, and all data stays in your browser's localStorage. The sample messages are illustrative and were written for this demo.

**Run it:** open `index.html`, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
